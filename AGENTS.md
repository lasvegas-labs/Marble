# Marble Contributor Guide

Read the relevant guide before changing code:

1. [Architecture](docs/architecture.md)
2. [Feature development](docs/feature-development.md)
3. [Routing](docs/routing.md)
4. [Code conventions](docs/code-conventions.md)
5. [Git workflow](docs/git-workflow.md)

Keep changes within the owning feature whenever possible. Update these guides in the same change only when a documented architecture, routing, dependency, or collaboration contract changes.

Do not add third-party dependencies without explicit approval. Prefer Swift and Apple frameworks, then dependencies already present in the project.
